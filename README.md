# 清风渡

> 一款古风仙侠题材的文字冒险游戏。玩家扮演一位独行侠客，误入雨夜山间客栈"清风渡"，与三位各怀心事的陌生人相遇，通过三天九时段的有限行动拼凑真相、影响结局。

## 项目结构


## 核心文档

| 文档 | 内容 |
|------|------|
| **PRD.md** | 产品定位、目标用户、核心玩法、美术/音频方向、技术要求、里程碑 |
| **PDD.md** | 世界观设定、角色档案、分支树、场景脚本、UI规格、音频设计、存档系统、结局总览 |
| **GameStudio.md** | 12角色四层架构（制作人→3总监→6执行→2产出），8阶段开发工作流 |

## 游戏概况

- **类型**：互动式视觉小说（橙光风格）
- **平台**：橙光游戏平台 / Steam
- **时长**：约 60–90 分钟（首次通关）
- **结局**：6 类 20+ 结局（CP/CB 双轨、正史、隐藏、彩蛋、死亡）
