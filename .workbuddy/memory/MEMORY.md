# 项目长期记忆

- 《清风渡》是以 Godot 4.x + GDScript 开发的古风仙侠互动视觉小说；PRD.md、PDD.md 与 project-ledger.json 是项目规范与进度的唯一事实来源。
- 用户要求后续所有 Godot 开发、美术、音频及相关内容生成严格遵循完整 PRD/PDD，禁止脱离世界观、角色、视听风格和技术架构自由发挥。项目专用约束入口为 `skills/qingfengdu_vibe_dev/SKILL.md`。
- 使用 game-studio 进行开发时，必须配套 project-ledger：开发前读取台账并校验依赖，验收后更新任务、交付物和汇总。
- 黎客颍立绘锁定为“清瘦精悍的青年刀客”：不纤弱、也不魁梧厚重；肩宽适中，腰身利落，前臂有适度力量感。常规平静立绘采用正脸直视、双手自然放松的正面站姿，不使用抱剑/抱刀姿势；武器是连鞘斜背于背后的单刃厚背朴素无纹长刀，旧黑皮缠柄、无纹无雕饰，禁止剑形护手或华丽装饰。
- 用户于 2026-08-07 确认归汉、黎客颍、柳陆书三张当前 MVP 立绘；归汉发色正式调整为墨黑长发，保留白袍、长剑与淡蓝剑穗，PRD/PDD 已同步。三位 MVP 运行时立绘统一存放于 `gotbotgame/assets/sprites/mvp/`，规格为 1600×2000 RGBA。
