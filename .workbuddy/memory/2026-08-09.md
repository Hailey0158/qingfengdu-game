## 修复 render_choices 强类型数组报错（P1-T9 缺陷）
- 报错：`_show_choice_response: Invalid type in function 'render_choices' ... argument 1 (Array) does not have the same element type`（Godot 运行时强类型校验）。
- 根因：`choice_panel.gd` 的 `render_choices(choices: Array[Dictionary])` 为强类型数组参数；`_show_choice_response` 传入无类型数组字面量 `[{"choice_id":..., "text":...}]`（默认 `Array`），类型不匹配。另一调用点 `_render_current_scene` 传 `runner.get_choices()`（本就返回 `Array[Dictionary]`）无此问题。
- 修复（方案1，推荐）：调用侧构造强类型数组 `var continue_choices: Array[Dictionary] = [...]` 再传入；未改 choice_panel.gd 签名与业务逻辑、未改 JSON。备选方案2为把签名弱化为 `render_choices(choices: Array)`，未采用。
