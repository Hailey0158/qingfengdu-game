## 修复选项按钮重复信号连接
- 问题：`_render_current_scene()` 每次切换场景时遍历 `choice_panel` 子节点并执行 `button.pressed.connect()`。但 `choice_panel.render_choices()` 用 `queue_free()` 删除旧按钮——`queue_free` 是延迟删除，旧按钮在本帧仍然存在于子节点列表。循环遍历到旧按钮时它们的 `pressed` 已连接过，再次 `connect` 触发 `ERR_INVALID_PARAMETER: Signal 'pressed' is already connected to given callable '_on_choice_pressed'`。
- 修复：第 59–63 行，先用 `_on_choice_pressed.bind(choice_id)` 构建 Callable，再用 `button.pressed.is_connected(callable)` 判断——仅在未连接时执行 `connect`。Godot 4 的 `is_connected` 会比较 Callable 的对象、方法和绑定参数，因此对带 `bind` 的 Callable 也能正确匹配。
- 未改动 `_on_choice_pressed` 业务逻辑；未新增 Autoload 或全局类。
- 静态校验通过：修复代码在位、业务逻辑完整、JSON 可解析、res:// 无断链。

  - `action_count` 永远不递增 → `scene_daily_return` 的条件路由（eq==1/eq==2/gte>=3）全部不满足 → 无选项出现 → 游戏卡死
  - `li_affection`/`gui_affection`/`fragments` 完全不被处理
  - `{"liu_met": true}` 等条件被跳过 → 所有 gated 选项始终显示
- **修复**：
  - `_apply_effects`：新增对 int 值（数值键 add / 标志键 set）和 bool 值（set 标志）的简写支持
  - `_conditions_met`：新增对 bool 值（检查标志匹配）和 int 值（检查 >= 该值）的简写支持，新增 `neq` 操作符
  - 新增 `_is_numeric_key` 辅助函数：统一判断 insight/liu_affection/li_affection/gui_affection/fragments/action_count
  - 新增 `_apply_numeric_effect` 辅助函数：统一处理所有数值键的 add/sub/set 操作，补齐 li_affection/gui_affection/fragments
  - `_read_numeric_state`：补齐 li_affection/gui_affection/fragments 的读取
- **影响范围**：仅修改 `mvp_scene_runner.gd`，未改分支树/对话/UI控制器/场景文件。

## 修复 Godot JSON 数字类型问题（float vs int）
- **根因**：Godot 4 的 `JSON.parse_string()` 将所有 JSON 数字解析为 `float`，不是 `int`。分支树中的简写效果如 `{"action_count": 1}` 在 GDScript 中 `effect` 类型为 `float(1.0)`，而非 `int(1)`。`effect is int` 返回 false → 效果被跳过 → `action_count` 不递增 → `scene_daily_return` 条件全部不满足 → 无选项出现 → 游戏卡死在"你做完手头的事，看了看窗外。雨还在下。"
- **修复**：`_apply_effects` 和 `_conditions_met` 中将 `if effect is int` 改为 `if effect is int or effect is float`，并对 float 值执行 `int(effect)` 转换。
- **影响范围**：仅修改 `mvp_scene_runner.gd`。
