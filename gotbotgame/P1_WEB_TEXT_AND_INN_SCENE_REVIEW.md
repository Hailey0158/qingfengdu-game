# P1 Web 乱码修复与客栈三人剧情图复核

日期：2026-08-07

## 1. 范围

本轮处理两个子项：

1. Web 端选项及动态文本乱码；
2. 基于三张已确认立绘和《目前.docx》客栈初识文案，生成适用于客栈大堂场景的 16:9 剧情大图。

未扩展剧情、分支、结局、战斗、卡牌或多时段内容。

## 2. Web 乱码审计结论

### 编码审计

- 所有 `.gd`、`.tscn`、`.json` 均为合法 UTF-8；
- 未发现 `�`、`锟斤拷`、`â€` 等典型编码损坏文本；
- 6 个 JSON 均可解析。

### 真实风险点

1. `choice_panel.gd` 原来使用 `▷` 作为选项引导符，但旧 `CMSFont-Bold.TTF` 不包含该字形；
2. 选项按钮在运行时动态创建，旧 `init_font.gd` 只在启动时递归处理已有控件，点击后新建的 Button 存在回退浏览器默认字体的风险。

修正后的字形复核：

- `CMSFont-Bold.TTF`：8662 个 cmap 字形，当前工程 585 个非 ASCII 字符 0 缺字，但缺少 `▷`；
- `NotoSansCJKsc-Regular.otf`：44810 个 cmap 字形，当前工程 585 个非 ASCII 字符 0 缺字，并覆盖 `▷`、中文标点、箭头及三位角色名。

## 3. 已执行修复

### 字体资源

新增：

- `fonts/NotoSansCJKsc-Regular.otf`
- `fonts/OFL-Noto-CJK.txt`

`fonts/README.md` 已更新为新字体、许可证来源与字形覆盖验证说明。

### 动态控件字体

`init_font.gd`：

- 字体路径改为 `res://fonts/NotoSansCJKsc-Regular.otf`；
- 保留启动时递归字体覆盖；
- 新增 `SceneTree.node_added` 监听，动态加入的 Control 会立即获得 `font` / `normal_font` / `bold_font` 覆盖。

`scripts/choice_panel.gd`：

- 动态 Button 创建时显式绑定同一项目字体；
- 选项引导符由 `▷` 改为稳定的 ASCII `>`，避免把装饰符号当成必需字形。
